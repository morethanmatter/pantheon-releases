# Pantheon downloads

[Download the latest Windows release](https://github.com/morethanmatter/pantheon-releases/releases/latest)

This repository contains Windows x64 installers, portable archives and signed update metadata. Application source is maintained separately in a private repository.

Install an updater-enabled release once on older machines. Afterward use Help → Check for Updates, or the blue download button, then Restart and Install. Saved projects and project-folder settings are retained. Portable ZIP copies are updated separately.

Pantheon verifies its Ed25519-signed release manifest and installer checksum before installation. The Windows executable does not yet carry an Authenticode publisher signature.

Published downloads require no GitHub account, source access, development checkout or shared drive.
